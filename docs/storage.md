# Storage

Default object storage is Tencent Cloud COS. CloudBase 云数据库 only stores metadata such as object keys, task states, prompts, and provider responses.

Object key layout:

- `recordings/{userId}/{timestamp}-{id}.mp3`: original humming recordings, permanent.
- `songs/demo/{userId}/{songId}.mp3`: generated demo songs, permanent.
- `songs/full/{userId}/{songId}.mp3`: generated full songs, permanent.
- `provider-artifacts/{provider}/...`: reserved for provider files or debug artifacts.

Provider URLs are treated as temporary. The worker must download provider output and persist it into COS before marking a song as ready.

Playback URLs are generated by the API as signed short-lived URLs unless `COS_CDN_BASE_URL` is configured.
